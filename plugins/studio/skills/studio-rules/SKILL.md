# Правила студии

## Главная папка и папка клиента

```
Главная папка студии/
  Библиотека студии/        общая для всех клиентов
    music/  sfx/  templates/  catalog.csv
  <Клиент>/                  Claude Code запускается здесь
    1. Исходники/
    2. Референсы/
    3. Брендбук/             брендбук клиента, лого, итоговый brandbook.json
    4. Premiere Pro/
      1. Нарезка/  v01/ v02/ …
      2. Графика/  v01/ …
      3. Тестовая минута/  v01/ …
      4. Ролик/  v01/ …
    5. Служебное/            пишет сайт — только читать (кроме шаблонов и работы)
      project.json  brandbook.json
      задания/<этап>.md
      шаблоны/               исходники шаблонов графики
      работа/                черновики, кадры, временные файлы
    ПРОЧТИ МЕНЯ.txt
```

Путь к библиотеке — `settings.library` в `5. Служебное/project.json`.

## Где работать

Работай только в текущей папке клиента и в библиотеке студии. Не ищи проекты в других папках компьютера и не меняй файлы вне папки клиента и библиотеки.

## Порядок работы любого этапа

1. Прочитай `5. Служебное/задания/<этап>.md` и `5. Служебное/project.json`. Задание главнее этих правил.
2. Проверь, что есть всё из раздела «Из чего собирать» или «Папки». Если чего-то нет, остановись и скажи, чего не хватает и какой этап сделать сначала.
3. **Версии.** Результат этапа клади в новую папку `vNN` внутри своего этапа в «4. Premiere Pro» (следующий свободный номер, две цифры). Прошлые версии не трогай: в них могут быть правки монтажёра и сохранённые .prproj. «Последняя версия» другого этапа — папка с самым большим номером.
4. Перед тяжёлым рендером покажи короткий план: что и где будет. Если пользователь рядом, дождись «да». Если он сказал работать без вопросов, работай.
5. Черновики и временные файлы — в `5. Служебное/работа/`, не в папки Premiere.
6. В конце дай короткий отчёт: что сделано, что не получилось, что проверить руками. Отчёт также сохрани как `report.md` в папке версии.

## Технические договорённости

- Пути с пробелами и кириллицей — в кавычках.
- Таймкоды: `ЧЧ:ММ:СС:КК` при 25 fps.
- Транскрипт: Whisper с таймкодами слов, русский. На Mac с Apple Silicon предпочтительно mlx-whisper (large-v3).
- Проект Premiere: FCP7 XML (`xmeml`). Пути к файлам — абсолютные `file://localhost/...` в URL-кодировке. Каждый элемент — отдельный clipitem. Файл .prproj ты создать не можешь: монтажёр импортирует XML и сохраняет проект в ту же папку версии.
- Дорожки: V1 исходник или нарезка, V2 бироллы и графика, V3 титры и субтитры, A1 голос, A2 музыка, A3 SFX.
- Лейбл клипа в FCP7 XML: `<labels><label2>Rose</label2></labels>` внутри clipitem. Имена лейблов как в Premiere: Violet, Iris, Caribbean, Lavender, Cerulean, Forest, Rose, Mango, Purple, Blue, Teal, Magenta, Tan, Green, Brown, Yellow.
- Графика с альфой: ProRes 4444, `ffmpeg -c:v prores_ks -profile:v 4444 -pix_fmt yuva444p10le`.
- Превью для сайта: H.264, 1280 px по длинной стороне, `-preset veryfast`, без звука для бироллов.
- Цвета и шрифты — только из `5. Служебное/brandbook.json`. Шрифты Google Fonts с кириллицей.
- Музыку и SFX бери только из библиотеки студии. Если есть `catalog.csv`, выбирай по нему, а не по имени файла.
- Голос всегда громче музыки: музыка под речью около −18…−22 dB относительно голоса.

## Честность

- Звук ты не слышишь. Настроение музыки и SFX оценивай по каталогу и метрикам и пиши в отчёте, что это оценка.
- Не утверждай, что Premiere откроет проект, если ты не проверил XML парсером.
