disable-model-invocation: true
---

Используй скилл studio-rules.

1. Прочитай `5. Служебное/project.json`: утверждённые вставки — ключи `client.likes`, библиотека — `settings.library.root` (обычно `../Библиотека студии`). Если библиотека не задана, спроси путь.
2. Возьми шаблоны утверждённых вставок из `5. Служебное/шаблоны/` и манифест последней версии `4. Premiere Pro/2. Графика/vNN/manifest.json`.
3. Для каждого шаблона сделай версию без привязки к клиенту: цвета, шрифты и тексты — параметры, значения по умолчанию нейтральные. Стиль клиента не копируй.
4. Сохрани в `<библиотека>/templates/<тип-раскладка>/` с `README.md` (как запустить, параметры) и `meta.json` (`name`, `layout`, `tracking`, `params`, `fromClient`, `preview`). Превью скопируй рядом.
5. Обнови `<библиотека>/templates/index.json` — список всех шаблонов с кратким описанием.
6. Покажи, что добавлено и что пропущено и почему.

Если пользователь передал аргументы к команде, учти их как уточнение задания.
